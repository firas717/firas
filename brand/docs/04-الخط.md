## 1. الخط المعتمد

**IBM Plex Sans Arabic** — خط واحد لكل شيء في القناة.

| | |
|---|---|
| التصنيف | سانس عربي حديث مبني على هيكل النسخ |
| التباين | منخفض — سماكة متجانسة عبر الحرف |
| المصمّم | Bold Monday — الجزء العربي: وائل مرقص وخجك أبيليان |
| الناشر | IBM Corp · 2019 |
| الإصدار | 1.101 |
| الترخيص | SIL Open Font License 1.1 |
| التضمين | `fsType = 0` — مسموح بلا قيود |
| المحارف العربية | 252 محرفاً · 1706 شكل حرف |
| تشكيل الحروف | مدعوم بالكامل — `init` `medi` `fina` `rlig` `ccmp` `calt` |

### لماذا هذا الخط تحديداً

1. **شقيق لاتيني مطابق** — `IBM Plex Sans` بنفس الهيكل والنسب، فالأرقام والكلمات الإنجليزية لا تنشاز داخل النص العربي. هذي أكبر مشكلة في القنوات العربية، وهذا الخط يحلّها بنيوياً.
2. **صُمّم للشاشات** — صعود ونزول قصيران وعيون مفتوحة، فيبقى مقروءاً في ٣٢ بكسل على جوال في الشمس.
3. **مجاني تجارياً** — رخصة OFL تسمح بالاستخدام والتضمين والبيع، بلا اشتراك ولا تراخيص.
4. **ليس مستهلكاً** — خط Cairo مستخدم في آلاف القنوات العربية، وهذا يميّزك.

## 2. الأوزان الثلاثة

| الوزن | الملف | الدور |
|---|---|---|
| **400 Regular** | `IBMPlexSansArabic-Regular.ttf` | المصادر، التواريخ، الأرقام، النصوص الثانوية |
| **600 SemiBold** | `IBMPlexSansArabic-SemiBold.ttf` | الترجمة المحروقة، عناوين المشاهد |
| **700 Bold** | `IBMPlexSansArabic-Bold.ttf` | سؤال الشريط العلوي، شريط الجزء، لقطة النهاية |

**الخط يأتي بسبعة أوزان** (Thin 100 · ExtraLight 200 · Light 300 · Regular 400 · Medium 500 · SemiBold 600 · Bold 700).
استُبعدت الأربعة الأخرى عمداً:

- **الخفيفة (100–300)** تختفي فوق الخلفيات المزدحمة في الشورتس.
- **Medium 500** قريبة جداً من SemiBold، ووجود وزنين متشابهين يفتح باب التردد بلا فائدة.

ثلاثة أوزان = التزام أسهل وهوية أكثر تماسكاً.

## 4. مكان الملفات

```
assets/fonts/
├─ IBMPlexSansArabic-Regular.ttf
├─ IBMPlexSansArabic-SemiBold.ttf
├─ IBMPlexSansArabic-Bold.ttf
└─ OFL.txt                ← رخصة الخط — لا تُحذف أبداً
```

رخصة OFL تشترط بقاء ملف الرخصة مع ملفات الخط عند أي توزيع.

**ممنوع استخدام `.woff2`** — صيغة ويب، و ffmpeg لا يقرأها عند حرق الترجمة.

## 5. التثبيت على النظام

**ويندوز:** حدّد الملفات الثلاثة ← زر يمين ← **Install for all users**
**ماك:** نقرة مزدوجة على كل ملف ← **Install Font**
**لينكس:**
```bash
mkdir -p ~/.local/share/fonts && cp assets/fonts/*.ttf ~/.local/share/fonts/
fc-cache -f -v
fc-list | grep -i "plex sans arabic"
```

التثبيت ضروري لبرامج المونتاج (بريمير، أفتر إفكتس، كاب كت). أما ffmpeg فيقرأ من المجلد مباشرة عبر `fontsdir`.

## 6. الاستخدام العملي

### ffmpeg — حرق الترجمة

```bash
ffmpeg -i in.mp4 -vf "ass=subs.ass:fontsdir=assets/fonts" \
  -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a copy out.mp4
```

### ffmpeg — نص مباشر على الفيديو

```bash
ffmpeg -i in.mp4 -vf "drawtext=\
fontfile=assets/fonts/IBMPlexSansArabic-Bold.ttf:\
text='النيرد':fontsize=74:fontcolor=white:x=(w-tw)/2:y=260" out.mp4
```

> `drawtext` **لا يشكّل الحروف العربية** ويعرضها مقطّعة. استخدمه للأرقام واللاتيني فقط.
> كل نص عربي يمرّ عبر ASS ليتولّى libass التشكيل.

### الأسماء الداخلية — مهمة جداً

| الوزن | الاسم الذي تكتبه في ASS أو البرامج |
|---|---|
| 400 | `IBM Plex Sans Arabic` |
| 600 | `IBM Plex Sans Arabic SemiBold` |
| 700 | `IBM Plex Sans Arabic` + تفعيل Bold |

> انتبه: **SemiBold عائلة منفصلة** باسمها الكامل، وليست وزناً داخل العائلة الأساسية.
> كتابة `IBM Plex Sans Arabic` مع وزن 600 لن تعطيك SemiBold.

### CSS — للثامبنيلات والصفحات

```css
@font-face{
  font-family:"IBM Plex Sans Arabic";
  src:url("assets/fonts/IBMPlexSansArabic-Regular.ttf") format("truetype");
  font-weight:400; font-display:swap;
}
@font-face{
  font-family:"IBM Plex Sans Arabic";
  src:url("assets/fonts/IBMPlexSansArabic-SemiBold.ttf") format("truetype");
  font-weight:600; font-display:swap;
}
@font-face{
  font-family:"IBM Plex Sans Arabic";
  src:url("assets/fonts/IBMPlexSansArabic-Bold.ttf") format("truetype");
  font-weight:700; font-display:swap;
}

body{
  font-family:"IBM Plex Sans Arabic","Segoe UI",Tahoma,sans-serif;
  direction:rtl;
}
```

### Python — للثامبنيلات المولّدة برمجياً

```python
from PIL import ImageFont
F = lambda w,s: ImageFont.truetype(f"assets/fonts/IBMPlexSansArabic-{w}.ttf", s)

d.text((x, y), "النيرد", font=F("Bold", 74), fill=(255,255,255),
       anchor="ra", direction="rtl", language="ar")
```

> `direction="rtl"` و `language="ar"` إلزاميان، ويحتاجان مكتبة **Raqm** مثبتة.
> تحقق: `from PIL import ImageFont; print(ImageFont.core.HAVE_RAQM)` — يجب أن تعطي `True`.

## 7. قواعد الكتابة العربية

- اتجاه النص `rtl` دائماً
- الحروف متّصلة — لا تفصل الحروف ولا تحرّكها فرادى
- الحركة تكون على **الكلمة كاملة أو السطر كاملاً**، لا على الحرف
- الأرقام: استخدم العربية الشرقية (٠١٢٣) أو الغربية (0123) — **واثبت على واحدة** في القناة كلها
- علامات الترقيم العربية: `،` و `؛` و `؟` — لا الإنجليزية
- لا تمدّد الحروف بالكشيدة لملء السطر

## 8. المشاكل الشائعة وحلولها

| العرض | السبب | الحل |
|---|---|---|
| الحروف مقطّعة: ا ل ن ي ر د | أداة لا تشكّل العربية | استخدم ASS مع libass، أو PIL مع Raqm |
| النص معكوس: دريـنلا | الاتجاه غير محدد | أضف `dir="rtl"` أو `direction="rtl"` |
| مربعات فارغة ☐ | الخط غير محمّل | تحقق من `fontsdir` أو من التثبيت |
| الوزن غلط | الاسم الداخلي غلط | راجع جدول الأسماء في القسم ٦ |
| Bold يبدو مشوّهاً | البرنامج ركّب وزناً صناعياً | حمّل ملف Bold الحقيقي |
| الخط يتغير في جهاز آخر | اعتماد على التثبيت | استخدم `fontsdir` ومرّر الملفات مع المشروع |

## 9. ممنوعات

- **خط Cairo** — مستهلك في آلاف القنوات العربية
- أي خط مزخرف أو مكتوب بالريشة
- الميل (italic) على العربية — لا وجود له في الخط العربي
- تركيب وزن صناعي بدل تحميل ملفه
- خلط خط عربي بخط لاتيني من عائلة أخرى
- استخدام أكثر من ثلاثة أوزان في المقطع الواحد
- حذف `OFL.txt` عند نقل الخط أو توزيعه
